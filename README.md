# Alabastro 1 · alabastro1.com.mx

Landing single-page para venta directa del predio Alabastro 1 (Milenio III, Querétaro).

## Stack
- HTML/CSS/JS vanilla (sin build step)
- Google Fonts: JetBrains Mono
- GitHub Pages + custom domain

## Estructura
- `index.html` — landing principal (scrollytelling 10 secciones)
- `assets/` — imágenes (fotos, mapa, chart, diagram, planos, posters)
- `assets/reels/` — posters SVG de los 6 reels + MP4 cuando se graben
- `*.pdf` — deck institucional + teasers descargables

## Deploy
GitHub Pages desde `main` branch · root.
Custom domain: `www.alabastro1.com.mx` (CNAME).
